🗂️ Gerenciador de Tarefas

Um aplicativo web simples e responsivo para criação, acompanhamento e conclusão de tarefas, desenvolvido em HTML, CSS e JavaScript puro.
O projeto foi desenvolvido com foco em semântica, acessibilidade, boas práticas de programação e persistência de dados via localStorage.


🚀 Funcionalidades

✅ Adiciona novas tarefas com:


Nome da tarefa
Etiqueta (tag)

Data de conclusão

✅ Exibe lista de tarefas automaticamente ao carregar a página
✅ Permite marcar tarefas como concluídas (toggle entre Concluir e ✔️ Check)
✅ Aplica estilo riscado em tarefas concluídas
✅ Exibe etiqueta e data de cada tarefa
✅ Mostra contador dinâmico e pluralizado de tarefas
✅ Armazena tudo no localStorage, mantendo as informações mesmo após recarregar a página
✅ Interface totalmente responsiva e acessível (com aria-live, labels e medidas em rem)
